DHCP consists of two components: 
protocol for delivering host specific configuration parameters from a DCP server
mechanism for allocation of network address to the host


Client -> someone that request the initialization parameter for a DHCP server


three mechanism supported by IP address allocation
automatic allocation -> where the DHCP assigns a permanent IP address to a host 
Dynamic allocation -> where the host tends to a temporary ip for only a certain period of time(or until the host explicitly relinquishes the address)
manual allocation -> where the ip is assigned by the networking administrator, what hte DHCP is used to simply convey assigned address to the host
